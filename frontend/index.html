Playback & setup hints

In Docker, playback defaults to LL-HLS on port 8888 (all TCP, works well on LAN). Low-latency WHEP: add ?playback=webrtc or VITE_PLAYBACK_MODE=webrtc (needs TCP/UDP 8189 for ICE; from another PC set MTX_WEBRTC_ADDITIONAL_HOSTS in .env). Add ?debug=1 for console traces. Each stream’s panel links to that backend’s OpenAPI /docs. Dual DL/UL: set VITE_API_BASE_DL and VITE_API_BASE_UL (see docker-compose.dlul.yaml).
